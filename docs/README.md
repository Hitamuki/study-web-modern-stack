# Docs

このディレクトリにはシステム全体の設計やドメインモデルに関するドキュメントを格納します。

## 収録内容

- `context-map.md` - バウンデッドコンテキストと各システム/サービスの連携を示すコンテキストマップ
- `domain-model.md` - ドメインエンティティ・値オブジェクト・集約境界などを示すドメインモデル図
- `er-diagram.md` - ER 図。**`schema.prisma` からの生成物**なので手で編集しない（#106）
- `er-diagram-notes.md` - ER 図の補足。**解説はこちらに書く**（生成物に書くと消えるため）
- `screen-list.md` - 画面IDの採番の正本。デザイン（`design/*.pen`）と実装の対応表
