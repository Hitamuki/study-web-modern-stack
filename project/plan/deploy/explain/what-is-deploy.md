# デプロイとは

**作ったプログラムを、誰かが使える場所に置いて動かすこと**です。

「置く」だけではなく「**動かし続ける**」のが要点です。ここで種類が分かれます。

| 種類 | 何をするか | 難しさ |
| :- | :- | :- |
| **静的ファイルを置く** | HTML / CSS / JS をサーバーに置く。あとは配るだけ | **易しい** |
| **プログラムを動かし続ける** | 常に起動していて、リクエストを待ち受ける | **難しい** |

前者は「本を図書館の棚に置く」ようなもので、置いたら仕事は終わりです。
後者は「窓口に人を座らせておく」ようなもので、**座り続けるコストがかかります。**

**無料で難しいのは後者です。** 誰かのコンピュータが動き続けるからです。

# このアプリは 4 つの要素に分かれる

**「Cloudflare にデプロイする」で片付かない**のがこの計画の出発点です
（Discussion [#29](https://github.com/Hitamuki/study-web-modern-stack/discussions/29)）。

| # | 要素 | 正体 | 種類 | 難しさ |
| :- | :- | :- | :- | :- |
| 1 | **Web**（`apps/web`） | React を変換した HTML / CSS / JS | 置くだけ | **易しい** |
| 2 | **Hasura** | Docker コンテナ（Haskell のプログラム） | 動かし続ける | **難しい** |
| 3 | **PostgreSQL** | データベース | 動かし続ける | 中程度 |
| 4 | **API**（`apps/api`） | Node.js のプログラム | 動かし続ける | 中程度 |

## なぜ Hasura が一番難しいのか

理由が 2 つあります。

**1 つめ: Cloudflare Workers のような「軽い実行環境」には載りません。**
ああいう環境は JavaScript を動かすためのもので、Hasura は **Haskell で書かれた実行ファイル**です。
言語が違うので、そもそも受け付けてもらえません。

**2 つめ: 止まっていられません。**
Hasura はデータベースとの接続を保ったまま、リクエストを待ち受けます。
「使われていないときは寝ていてよい」形にすると、
起きるのに時間がかかり（**コールドスタート**）、最初のアクセスが遅くなります。

## なぜ Web は易しいのか

`apps/web` は React で書かれていますが、**公開するときには HTML / CSS / JS に変換されます。**

```text
apps/web/src/**.tsx  ──[ vite build ]──▶  apps/web/dist/  （ただのファイル）
```

**変換後はプログラムではなく、ただのファイルの集まり**です。
置いておけば誰でも取りに来られるので、無料で配ってくれるサービスがたくさんあります。

# 「デプロイ」に含まれる作業

置くだけでは動きません。実際には次がセットになります。

| 作業 | 内容 | このリポジトリの現状 |
| :- | :- | :- |
| **ビルド** | ソースコードを動く形に変換する | `make build` で可能 |
| **コンテナ化** | プログラムを「どこでも動く箱」に詰める | **Dockerfile が 1 つも無い** |
| **設定の注入** | 接続先やパスワードを外から渡す | **一部がコードにベタ書き** |
| **配置** | 箱をサービスへ送る | 未着手 |
| **自動化** | 上記を CI が自動でやる | **`.github/workflows` が無い** |

**このリポジトリはこの 5 つのうち 3 つが未着手です。** だから
[段階 1](/project/plan/deploy/objective.md) が要ります。

## コンテナとはなにか

**プログラムと、それが動くのに必要なもの一式を、1 つの箱に詰めたもの**です。

「自分の PC では動くのに、サーバーでは動かない」を防ぐために使います。
OS のバージョンやライブラリごと箱に入れるので、**箱ごと運べばどこでも同じように動きます。**

このリポジトリは既に Hasura と PostgreSQL を**コンテナとして使っています**
（`docker-compose.yml`）。ただしそれは**公開されている箱を借りているだけ**で、
`apps/api` を箱に詰めたことは一度もありません。
→ [../layer-container.md](/project/plan/deploy/layer-container.md)
